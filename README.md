## Install

This app is distributed outside the Google Play Store, so Android may ask for permission before installing it.

1. Open the download link above in Chrome.
2. Download `KUKA_TEC_1.apk`.
3. Open **Files → Downloads** and tap `KUKA_TEC_1.apk`.
4. If Android blocks installation, open **Settings**.
5. Enable **Allow from this source**.
6. Return to the installer.
7. Tap **Install** and then **Open**.

### Enable installation permission manually

If the permission screen does not appear automatically:

**Settings → Apps → Special app access → Install unknown apps → Chrome → Allow from this source**

The menu may be slightly different depending on the phone manufacturer.

- **Samsung:** Settings → Apps → ⋮ → Special access
- **Xiaomi / Redmi / POCO:** Settings → Privacy protection → Special permissions
- **Realme / OPPO:** Settings → Password & security → System security
- **Android 7 and older:** Settings → Security → Unknown sources

You may also need to grant the same permission to **Files** or **My Files**.

## Troubleshooting

### Downloaded file is only a few kilobytes

You may have downloaded the GitHub webpage instead of the APK.

Use the **Download KUKA_TEC_1.apk** link at the top of this README.

### App not installed

If an older version of the application is already installed, uninstall it first and try again.

### App not compatible with your device

Check that your device is running **Android 8.0 or newer**.

### Problem parsing the package

The APK may not have downloaded completely.

Delete the downloaded file and download it again using a stable internet connection.
