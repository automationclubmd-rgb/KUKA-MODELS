## Install

This app is distributed outside the Play Store, so Android will ask for
permission before installing it. That is normal and takes about ten seconds.

1. Open the download link above in Chrome. The APK saves to your **Downloads**
   folder.
2. Chrome warns *"This type of file can harm your device."* Tap **Download
   anyway**. This warning appears for every APK and is not a virus detection.
3. Tap the download notification, or open **Files → Downloads** and tap
   `KUKA_TEC_1.apk`.
4. Android says *"your phone isn't allowed to install unknown apps from this
   source."* Tap **Settings** in that message.
5. Turn on **Allow from this source**, then press back. The install continues.
6. If Play Protect shows *"Unsafe app blocked,"* tap **Install anyway**. This
   appears because the app isn't signed by a Play Store developer account.
7. Tap **Install**, then **Open**.

### Turning on the permission manually

If step 4 never appears, grant it yourself:

**Settings → Apps → Special app access → Install unknown apps → Chrome →
Allow from this source**

The menu is named slightly differently on some phones:

- **Samsung** — Settings → Apps → ⋮ → Special access
- **Xiaomi / Redmi / POCO** — Settings → Privacy protection → Special permissions
- **Realme / OPPO** — Settings → Password & security → System security
- **Android 7 and older** — Settings → Security → Unknown sources (one global switch)

Grant the same permission to **Files** or **My Files**, since that app is often
what actually launches the installer.

## Troubleshooting

**The downloaded file is only a few kilobytes**
You saved the GitHub web page instead of the app. Use the download link at the
top of this page, which contains `/raw/` in the address.

**"App not installed"**
An older copy is already on the phone. Uninstall it first — a rebuilt APK cannot
overwrite an existing install unless both were signed with the same key.

**"App not compatible with your device"**
The phone runs an older Android version than the app requires, or the phone's
processor architecture isn't included in this build.

**"There was a problem parsing the package"**
The download was cut off partway. Delete the file and download it again on a
stable connection.
